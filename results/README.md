# results/ — committed measurement artifacts

This directory is **tracked in git**. It holds the canonical, verified measurement
output for this repository, so the numbers cited in reviews, the PR and
`MEASUREMENT.md` can be inspected without re-running anything, and any post-hoc
tampering is detectable via the manifest.

## Index

Machine-readable index: **`manifest.json`** — for every file: path, SHA-256, byte
count; for the JSONL results: record histogram, meta fingerprint (profile, seed,
timestamp, commit, go version), summary footer, and the verification verdict.
Regenerate or check it with:

```sh
make measure-index    # bigbuff-measure index --dir results --out results/manifest.json
```

The index command fails (exit 1) if any JSONL file fails verification, so
`results/manifest.json` with `"verified": true` on both `.jsonl` entries is the
statement of record. It does not hash itself; diff a regenerated manifest to detect
drift in any other artifact.

| file | what it is | generated by |
|---|---|---|
| `measurements.jsonl` | Standard-profile results (2013 records, 5 reps, subs up to 256). Verification: **PASS** (broadcast 77/77, caster 13 measured + 5 exposure-limited skips, scatter 4/4, gather 2/2, payload 19/19) | `make measure-standard` |
| `quick.jsonl` | Quick-profile results (1479 records) for fast CI-style spot checks. Verification: **PASS** | `make measure-quick` |
| `report.html` | Interactive self-contained HTML report built from `measurements.jsonl` (scaling curves, leaderboard, adoptability radar, stalled-consumer Pathology Lab with swimlane traces, coverage matrix, downloads). Open it directly in a browser; everything is embedded. | `make measure-report` |
| `registry.json` | Scenario/case/attachment registry dump (18 scenarios — kind, baseline, invariants — plus 291 good/bad-fit attachments with remarks and exposure-limit flags). | `make measure-registry` |
| `csv/metrics_wide.csv` | One row per metric record, all statistical columns flattened. | `make measure-report` |
| `csv/scores.csv` | Per-family adoptability scores, dimension breakdowns and verdicts. | `make measure-report` |
| `manifest.json` | SHA-256 index of all of the above (see above). | `make measure-index` |

## Provenance

- Toolchain: go1.27.3 (linux/amd64), GOMAXPROCS=2, `bigbuff-measure` schema v1.
- Both `.jsonl` runs were produced by the same source revision as this directory
  (post drop-oldest dispatcher/admission fixes in `baseline_async.go` and
  `ringfanout_14_xing.go`); `git log` for this directory shows the exact commits.
- `report.html` embeds the standard-profile dataset; its embedded `registry` block
  matches `registry.json` from the same revision.

## Refreshing artifacts

Artifacts are **not** auto-generated by the test suite; they are regenerated
explicitly and committed deliberately:

```sh
make measure              # run standard → verify → report
make measure-quick        # or: CI-grade quick profile
make measure-index        # rebuild the SHA-256 index
git add results/          # commit the refresh explicitly
```

`make clean` deliberately does not touch this directory. Sizes (~7 MB total) are
kept small by storing only the standard + quick profiles; the full profile is
regenerable on demand (`make measure-full`) and intentionally not committed.
